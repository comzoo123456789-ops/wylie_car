# WYLIE 법인차량 자동 관리 시스템

## 프로젝트 개요
- **이름**: WYLIE Car System
- **목표**: 법인차량의 월별 주행기록(출퇴근/업무용)을 자동 분배하고 운행일지를 엑셀로 출력
- **주요 기능**:
  - 차량별 마스터 정보 표시 (모델, 사용자, 보험, 렌탈료)
  - 계기판 사진 업로드 미리보기
  - 최종 주행거리 입력 시 영업일/휴일 기준 출퇴근·업무용 자동 분배
  - 운행기록부 엑셀(.xlsx) 다운로드

## URL
- **개발 서버 (Sandbox)**: https://3000-i0ossnwg0jidamskm7cd7-a402f90a.sandbox.novita.ai
- **API 엔드포인트**:
  - `GET /api/cars` - 전체 차량 목록
  - `GET /api/cars/:num` - 특정 차량 정보

## 데이터 아키텍처
- **데이터 모델**: 차량(번호판, 모델, 사용자, 보험정보, 렌탈료, 시작 주행거리)
- **저장소**: 현재 메모리 내 객체 (추후 Cloudflare D1 또는 KV로 확장 가능)
- **분배 로직**: 영업일에 출퇴근 10km 고정 + 잔여 거리를 영업일에 랜덤 분배

## 사용 가이드
1. 상단 탭에서 차량(187너4662, 40로2593, 150하1559) 선택
2. 당월 최종 계기판 거리 입력
3. 계기판 사진 업로드 (선택)
4. "데이터 자동 분배 및 저장" 클릭 → 5월 운행일지 자동 생성
5. "엑셀 저장" 버튼으로 .xlsx 파일 다운로드

## 배포
- **플랫폼**: Cloudflare Pages
- **상태**: ✅ 로컬 개발 중 (배포 대기)
- **기술 스택**: Hono + TypeScript + TailwindCSS + Vite + Cloudflare Workers
